# Configuration

Every one of the **94 settings** Aurum reads, what it defaults to, and
why it exists.

> Generated by `python scripts/gen_configuration.py` from `app/config.py`.
> The defaults and environment variable names are read out of the `SPEC`
> table itself, and each explanation is the comment standing above that
> entry in the source. Nothing here is typed by hand, so it cannot drift
> from the code it describes.

## How a value is resolved

Three sources, last one wins:

1. The default in this table.
2. `configs/*.yaml`, by the dotted key.
3. The environment variable.

A profile script such as `configs/bench-profile.sh` is just the third of
these: it exports environment variables and nothing more. `UNMEASURED` is a
real value meaning *nobody has measured this on the physical machine*, and
the code that consumes it refuses rather than guessing.
